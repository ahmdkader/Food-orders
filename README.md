# ورقة الطلب 🍽️

تطبيق لتنظيم طلبات أكل الشركة: تصويت على المطعم، كل واحد يكتب طلبه، حساب أوتوماتيك (بالضريبة والتوصيل)، ودفع (لينك إلكتروني أو كاش) — وفيه شات للمناقشة. شغال بين كل الزمايل لحظياً لأنه بيستخدم Firebase كـ"سيرفر" مجاني.

## الخطوة 1: اعمل مشروع Firebase (مجاني، تاخد 3 دقايق)

1. روح [console.firebase.google.com](https://console.firebase.google.com) وسجل دخول بحساب جوجل.
2. اضغط **Add project** واكتب أي اسم (مثلاً `company-lunch`)، وكمّل الخطوات (تقدر توقف الـ Google Analytics).
3. من القائمة الجانبية: **Build → Realtime Database** → **Create Database** → اختار أي منطقة قريبة → ابدأ في **Test mode**.
4. بعد ما يتعمل، روح تبويب **Rules** فوق واستبدل اللي موجود بده واضغط **Publish**:
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
   ⚠️ ده بيخلي أي حد معاه اللينك يقدر يقرأ ويكتب — مناسب لأداة داخلية بسيطة بين الزمايل، مش لبيانات حساسة.
5. ارجع لصفحة المشروع الرئيسية (اضغط على اسم المشروع فوق أو أيقونة البيت 🏠). هتلاقي تحت عنوان "Get started by adding Firebase to your app" كذا أيقونة (أندرويد / آيفون / </> ). **اضغط على أيقونة </> ("Web")**.
   - هيفتحلك فورم اسمه "Register app"، اكتب أي اسم في خانة "App nickname" (مثلاً `lunch-app`) — الاسم ده شكلي بس مش مهم.
   - **متضغطش** على تفعيل "Also set up Firebase Hosting" — سيبها من غير علامة صح.
   - اضغط **Register app**.
6. أول ما تضغط Register app، هتظهرلك صفحة فيها كود جافاسكريبت شكله كده تقريباً:
   ```js
   const firebaseConfig = {
     apiKey: "AIzaSyD...........",
     authDomain: "lunch-app-xxxxx.firebaseapp.com",
     databaseURL: "https://lunch-app-xxxxx-default-rtdb.firebaseio.com",
     projectId: "lunch-app-xxxxx",
     storageBucket: "lunch-app-xxxxx.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef123456"
   };
   ```
   إنت محتاج بس **4 قيم من الكود ده**: `apiKey`, `authDomain`, `databaseURL`, `projectId` — سيب الباقي (`storageBucket`, `messagingSenderId`, `appId`) متعملهاش حاجة، مش محتاجهم.
   - لو دوّرت على الصفحة دي تاني بعدين ملقتهاش، تقدر توصلها من: أيقونة الترس ⚙️ (فوق شمال) → **Project settings** → انزل تحت لحد "Your apps" هتلاقي نفس الكود موجود هناك تاني.

## الخطوة 2: حط بيانات Firebase في الكود (مرة واحدة بس، وانت اللي بتعملها)

افتح ملف `index.html` بأي محرر نصوص، وفي أول الكود (تحت السكريبت) هتلاقي:

```js
const FIREBASE_CONFIG = {
  apiKey: "ضع-الـ-apiKey-هنا",
  authDomain: "ضع-الـ-authDomain-هنا",
  databaseURL: "ضع-الـ-databaseURL-هنا",
  projectId: "ضع-الـ-projectId-هنا",
};
```

استبدل القيم دي بالبيانات اللي نسختها من Firebase (الأربع قيم دول موجودين في نفس الكود اللي نسخته من هناك). احفظ الملف. **دي الخطوة الوحيدة اللي محتاجة تعديل يدوي**، وهتعملها إنت مرة واحدة بس قبل ما ترفع المشروع — مفيش أي حد تاني هيحتاج يعمل حاجة زي كده. (البيانات دي مش سر، آمن تماماً إنها تكون ظاهرة في الكود — الحماية بتبقى من قواعد الـ Database اللي ظبطناها فوق.)

## الخطوة 3: ارفع المشروع على GitHub

1. اعمل repository جديد على GitHub (public أو private، الاتنين شغالين مع Pages).
2. ارفع كل الملفات اللي في الفولدر ده (`index.html` بعد ما عدّلته، `manifest.json`, `sw.js`, `icon.svg`, `README.md`) لجذر الـ repo.
3. من إعدادات الـ repo: **Settings → Pages** → تحت **Branch** اختار `main` والفولدر `/ (root)` → **Save**.
4. بعد دقيقة أو اتنين هيديك لينك زي:
   `https://username.github.io/repo-name/`

## الخطوة 4: ابعت اللينك للزمايل

كل حد يفتح اللينك مباشرة، مطلوب منه بس يكتب اسمه — من غير أي كود أو نسخ ولصق — وهيبقى شايف نفس التصويت والطلبات مع الباقي لحظياً.

## تثبيت التطبيق على الموبايل (زي أي أبلكيشن عادي)

- **أندرويد (كروم):** افتح اللينك → القائمة (⋮) → **Add to Home screen / إضافة إلى الشاشة الرئيسية**.
- **آيفون (سفاري):** افتح اللينك → زرار المشاركة (⬆️) → **Add to Home Screen**.

هيظهرله أيقونة على الشاشة الرئيسية ويفتح بملء الشاشة زي أي تطبيق تاني.

## ملاحظات

- منيو المطعم: تقدر تضيف **لينك** (مثلاً صورة على جوجل درايف) أو **ترفع صورة/PDF** مباشرة — الصور بتتضغط أوتوماتيك، لكن لو الملف كبير أوي (أكتر من ٣ ميجا) يفضل تحطه لينك بدل الرفع عشان الأداء.
- الضريبة اختيارية لكل يوم — فعّلها من تبويب الحساب لو المطعم بيحسبها، واكتب النسبة.
- زرار "بدء يوم جديد" بيفتح جلسة جديدة فاضية من غير ما يمسح بيانات اليوم اللي فات.
- لو عايز تأمين أقوى بدل القاعدة المفتوحة، ممكن تضيف Firebase Authentication لاحقًا — قولي لو عايز مساعدة في الخطوة دي.
